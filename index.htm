Exemplo de Flexbox: justify-content

Esta propriedade alinha os itens flex ao longo do eixo principal. Os valores podem ser 'flex-start', 'center', 'space-between', etc.

.container { display: flex; justify-content: space-around; }

Exemplo de Flexbox: align-items

Isso alinha os itens flex ao longo do eixo transversal. Experimente valores como 'flex-start', 'flex-end' ou 'stretch'.

.container { display: flex; align-items: center; }

Exemplo de Grid: grid-template-columns

Define o número e os tamanhos das colunas em um layout de grade. Pode usar unidades fr, porcentagens ou valores fixos.

.container { display: grid; grid-template-columns: 1fr 1fr 1fr; }
